# Dokumentasi Kullo

Folder ini menyimpan dokumen produk dan rencana. Halaman aplikasi tidak membaca
file di sini; dokumen ini untuk manusia.

## Struktur

- `docs/specs/DATABASE.md` — spesifikasi modul Database/CRM (belum diterapkan).
- `docs/specs/DRIVE.md` — eksperimen tampilan Drive (dibatalkan).
- `docs/specs/KULLO.md` — PRD produk dan cakupan modul.
- `docs/specs/PLAN.md` — rencana menuju production, web + mobile.
- `docs/specs/WORK.md` — catatan ruang lingkup pekerjaan.

## Dokumen yang tetap di root

- `DESIGN.md` — sumber kebenaran design system (Fluent 2).
- `MOBILE.md` — sumber kebenaran layout dan interaksi mobile.
- `AGENTS.md` — instruksi kerja agen di repo ini.

Ketiganya sengaja tetap di root karena dirujuk sebagai entry point oleh
instruksi repo dan alat desain.

## Artefak lain

- `replica/` — recon, arsitektur, route map, build log, test plan, dan screenshot.
- `replica/screens/adhoc/` — tangkapan layar eksplorasi di luar bukti rilis.
- `public/shots/` — screenshot yang dipakai halaman marketing.
- `public/illustrations/` — ilustrasi SVG auth dan lisensinya.
