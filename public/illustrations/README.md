These SVG illustrations are used on the full-screen authentication screens
(`/masuk`, `/daftar`, `/gabung`).

- **Source:** unDraw — <https://undraw.co> (open-source illustrations, free for
  personal and commercial use, no attribution required).
- **Files obtained from:** the MIT-licensed mirror
  <https://github.com/balazser/undraw-svg-collection> (SVGs from unDraw):
  - `auth-login-hero.svg` — `svgs/login.svg`
  - `auth-authentication-hero.svg` — `svgs/authentication.svg`
  - `auth-secure-login-hero.svg` — `svgs/secure-login.svg`
- **Palette:** recoloured with DESIGN.md §2 brand and neutral values only:
  `#0F6CBD` (brand), `#115EA3` (brand hover), `#0C3B5E` (brand pressed),
  `#EBF3FC` / `#F0F6FC` (brand light), `#F5F5F5` / `#F0F0F0` / `#E8E8E8` /
  `#D6D6D6` (neutral), `#FFFFFF` (surface). No unDraw colour is shipped.
